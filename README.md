# Gyanexia - Modern Study & Learning Platform

A modern, high-performance, and comprehensive study & learning platform for **Gyanexia**—founded by **Nikhil Prajapati (IIT Kanpur)**.

---

## 🌟 Key Features

1. **Brand & Identity**:
   - Official Gyanexia logo and crimson/coral brand aesthetic.
   - Announcement ticker with live updates for *Gyanexia Talent Hunt 2026*.
   - Founder spotlight honoring Nikhil Prajapati (IIT Kanpur) with authentic quotes and mission statement.

2. **Interactive Timed Test & Examination Simulator (`GyanExam`)**:
   - Practice diagnostic tests for Class 5 to 12.
   - Real-time countdown timer, question palette with status tracking (Answered, Unanswered, Review, Unvisited).
   - Instant scorecard with accuracy %, marks tally, and step-by-step solution breakdowns.

3. **Study Materials & Question Bank Hub**:
   - Class-wise filters (Class 5 to 12).
   - Subject categories: Mathematics, Science, Logical Reasoning, AI & Coding, Solved PYQs.
   - Formula cheat sheets, handwritten notes, and Daily Practice Problems (DPPs).

4. **Gyanexia Talent Hunt 2026 Portal**:
   - Live countdown timer to December 2026 exam.
   - Prize breakdown (₹5,00,000+ Scholarships, Laptops, IIT Mentorship).
   - Interactive Pre-Registration modal with an **instant downloadable / printable Official Admit Card & Pass**!

5. **Class-wise Participation & Analytics**:
   - Chart.js interactive visualization matching Gyanexia's competition participation across grades (Class 5 to 12).
   - Subject mastery radar chart.

6. **Classroom Examination Photo Gallery**:
   - Interactive carousel featuring real Gyanexia student offline examinations and summer camp workshops.

7. **GyanAI Academic Study Buddy**:
   - Interactive AI doubt solver and academic assistant.

8. **Focus & Productivity Tools**:
   - Built-in **Pomodoro Focus Study Timer** (25 min study / 5 min break cycles).
   - **Dark & Light Mode Switcher** with preference memory.
   - **Global Search (Ctrl + K)** across all courses, topics, and study resources.

---

## 🚀 How to Run

### Direct Browser Opening
Simply double-click or open `index.html` in any web browser!

### Running with Python Server
```bash
cd gyanexia-platform
python server.py
```
Then visit: **http://localhost:8000** in your browser.
